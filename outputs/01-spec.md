# 01 명세 — 맵 구조 · 특수 장치 (초안, 사용자 승인 전)

기준 문서: `HANDOFF.md` 4-2절. 이 문서는 "맵을 데이터 파일로 만들고, 맵마다 고유 장치를 부품처럼 붙인다"를 구체화한 것이다.
(AI 문제 생성 설계서는 별도 `02-spec-questions.md` 로 이어서 작성 예정)

## 1. 목표
- 맵을 추가할 때 **게임 코드를 고치지 않고 맵 데이터 파일 하나만 추가**하면 된다.
- 맵마다 고유한 장치(미끄럼틀, 개구멍 등)를 **공통 부품의 조합**으로 만든다.

## 2. 맵 데이터 파일 (맵 1개 = 파일 1개, 예: `maps/monster-gym.json`)
| 항목 | 내용 |
|---|---|
| `id`, `name`, `size` | 맵 식별자, 표시 이름, 크기(참고작은 2800×1900) |
| `rooms` | 방 사각형 목록 (이름, 위치, 크기, 바닥 종류) |
| `corridors` | 복도 사각형 |
| `doors` | 문 위치, 잠금 가능 여부 (방해꾼 "문 잠금" 대상) |
| `walls` / `furniture` | 막힌 곳. 20px 격자로 충돌 계산 |
| `terminals` | 문제 단말기 위치 (+ 선택: 과목 태그) |
| `spawn` | 시작 위치 |
| `meetingButton` | 긴급회의 버튼 위치 (얼음땡 모드에서는 무시) |
| `devices` | 특수 장치 목록 (3절) |
| `zones` | 구역 효과 목록 (4절) |

- 역할별 통과 규칙: 충돌 격자에 **역할 칸**을 둔다 (예: 술래만 막힘, 방해꾼만 통과).
- 맵 검증기: 파일을 읽을 때 "시작 위치가 막힌 곳이 아닌가, 단말기가 도달 가능한가, 장치 짝(출구)이 있는가"를 자동 확인한다. (제안)

## 3. 특수 장치 = 작은 부품
장치 하나는 **누가 · 언제 · 무슨 효과** 세 가지로 정의한다.

```
{
  "id": "...", "type": "slide|teleport|gate|switch", "when": "enter|press|always",
  "who": { "freeze-tag": ["student"], "impostor": ["student", "saboteur"] },
  "cooldown": { "scope": "player", "seconds": 10 },
  "protectAfter": 1
}
```
- `who` 는 **모드별로** 적는다 (얼음땡 `freeze-tag`, 어몽어스 `impostor`). 같은 장치라도 모드에 따라 쓸 수 있는 역할이 다르기 때문이다.
- `cooldown.scope` 가 `player` 면 쓴 사람만, `device` 면 장치 전체가 잠긴다. 기본은 `player` 10초.
- `protectAfter` 는 도착 후 보호 시간(초). 타는 동안은 항상 못 잡는다.
- 종류별 추가 항목: slide 는 `from/to/duration`, teleport 는 `from/exits/exitPick/duration`.

기본 부품(처음에 만들 것):
1. **teleport(순간이동)** — 입구→출구. 개구멍, 순간이동 문. 위치 전송과 별개의 **이벤트**로 처리, 1~2초 연출. 출구는 한 곳 또는 여러 곳 중 랜덤.
2. **slide(미끄럼틀)** — 정해진 방향으로 빠르게 이동. `who` 에서 술래를 빼면 "술래는 못 탐".
3. **zone 효과** — 감속, 가속, 시야 축소, 소리 없음 등 (4절).
4. **gate(역할별 문/통로)** — 특정 역할만 통과. 방해꾼 전용 통로 등.
5. **switch(스위치)** — 누르면 다른 장치를 잠시 켜거나 끔 (열쇠 문, 회전 책장).

## 4. 구역 효과(zone) 종류 (제안)
`slow`(감속) · `fast`(가속) · `slippery`(미끄러짐) · `dark`(시야 축소) · `quiet`(조용히 구역: 느려짐) · `safe`(술래/방해꾼 능력 사용 불가)

## 5. 첫 맵 후보와 장치 (제안: 우선 2개로 시작)
| 맵 | 고유 장치 | 비고 |
|---|---|---|
| 몬스터 체육관 | 미끄럼틀(술래 불가·학생 빠른 탈출), 개구멍(다른 곳으로 나타남) | 사용자 확정 예시. **1번 맵** |
| 도서관 | 회전 책장(switch+teleport), 조용히 구역(quiet) | 2번 맵 후보 |
| 수영장/실험실 | 젖은 바닥(slippery), 감속 구역 | 후보 |
| 지하 창고 | 어두운 구역(dark), 열쇠 문(switch) | 후보 |
| 놀이공원 | 점프대, 회전목마 | 후보 |

## 6. 확정된 규칙 (2026-11-20 사용자 확정)
1. **개구멍 출구**: 여러 곳(2~3곳) 중 랜덤. 술래가 출구에서 기다리는 것을 막는다.
2. **이동 중 잡기**: 장치를 타는 동안은 못 잡고, 도착 후 1초 동안도 보호된다.
3. **쿨타임**: 사람마다 10초. 같은 장치를 쓴 사람만 10초 동안 다시 못 쓰고, 다른 사람은 바로 쓸 수 있다.
4. **방해꾼의 장치 사용**: 어몽어스 모드의 방해꾼은 학생과 똑같이 쓸 수 있다(정체가 드러나지 않게). 얼음땡 모드의 술래만 못 탄다.
5. **맵 그림**: 밝고 코믹한 만화풍으로 만든다. 구조는 코드로 그리고 배경·장식은 Codex 일러스트를 입힌다 (`04-spec-graphics.md`, 처음의 "도형 먼저" 결정을 대체).
6. **첫 맵**: 몬스터 체육관 1개부터. 샘플 데이터는 `outputs/code/maps/monster-gym.json`.
