# 02 명세 — 미션 문제 만들기 (엑셀 업로드 방식)

기준 문서: `HANDOFF.md` 4-1절 + 2026-11-20 사용자 결정(`00-decisions.md`).
목표는 "문제를 고정하지 않고, 선생님이 수업 직전에 만들어 넣는다"이다.

## 1. 확정된 방향 (2026-11-20)
- 문제는 **엑셀(xlsx) 파일을 올려서** 넣는다. 사용자가 다른 게임(퀴즈카트)에서 쓰던 양식을 그대로 쓴다.
- 게임 안에서 AI를 직접 부르는 기능은 **나중에** 만든다. 1단계는 서버·API 키·비용이 필요 없다.
- 문제에 **그림은 넣지 않는다.**
- 게임 중 정답 판정은 AI가 아니라 **코드**가 한다.

## 2. 엑셀 양식 (기준 파일: `퀴즈카트_사회_2-3_무역.xlsx` 과 같은 구조)
시트 이름 `문제`, 첫 줄은 제목 줄, 둘째 줄부터 한 줄에 문제 하나.

| A 문제 | B 정답 | C 오답1 | D 오답2 | E 오답3 |
|---|---|---|---|---|
| 나라와 나라 사이에 물자나 서비스를 사고파는 일은? | 무역 | 소비 | 생산 | 저축 |
| 다른 나라에서 수입하는 상품에 부과하는 세금은? | 관세 | | | |

문제 형식은 **오답 칸이 채워졌는지**로 자동 결정한다.
| 오답 칸 | 형식 | 학생 조작 | 정답 판정 |
|---|---|---|---|
| 모두 비어 있음 | 단답형(주관식) | 글자 입력 | 정답과 일치 (앞뒤 공백·띄어쓰기·대소문자 무시) |
| 3개 모두 채움 | 4지선다 | 보기 하나 누르기 | 정답 보기 선택. 보기 순서는 학생마다 섞는다 |

- 오답이 1~2개만 있으면: 있는 만큼으로 2~3지선다를 만든다. (제안)
- 파일 이름(확장자 제외)을 문제 세트 제목으로 쓴다. 업로드 후 고칠 수 있다. (제안)
- 양식에 없는 것: 힌트·해설·난이도. → 9절 확인 필요.

## 3. 선생님이 문제를 만드는 흐름
1. 게임 사이트의 "미션 문제 만들기"에서 **[빈 양식 내려받기]** → 제목 줄만 있는 xlsx.
2. **[AI 요청문 보기]** → 팝업창에 요청문(프롬프트)이 뜬다. **[복사]** 버튼.
3. 선생님이 쓰는 생성형 AI(ChatGPT·Gemini 등)에 **교과서 PDF 같은 자료를 첨부**하고 요청문을 붙여넣는다 → AI가 양식대로 채운 엑셀을 만들어 준다.
4. 그 xlsx 를 게임 사이트에 **[올리기]** → 형식 검사 → 미리보기 → **[이 세트로 확정]** → 미션 문제 완성.

직접 엑셀에 손으로 써서 올려도 똑같이 된다.

### 3-1. AI 요청문 (초안 — 팝업에 그대로 들어갈 문구)
```
첨부한 자료의 내용으로 초등학생용 퀴즈 문제 30개를 만들어 엑셀(xlsx) 파일로 주세요.

[엑셀 형식]
- 시트 이름: 문제
- 첫 줄(제목): 문제 | 정답 | 오답1 | 오답2 | 오답3
- 둘째 줄부터 한 줄에 문제 하나

[문제 규칙]
- 문제는 한 문장, 50자 이내. 그림이나 표를 봐야 풀 수 있는 문제는 만들지 않습니다.
- 4지선다 문제: 정답 1개와 오답 3개를 모두 채웁니다. 보기는 20자 이내.
- 주관식 문제: 정답만 쓰고 오답 칸은 비워 둡니다. 정답은 낱말 하나(10자 이내)로, 답이 여러 가지로 쓰일 수 있는 문제는 피합니다.
- 4지선다 약 70%, 주관식 약 30% 로 섞습니다.
- 쉬운 문제와 어려운 문제를 고르게 섞고, 같은 내용을 묻는 문제를 반복하지 않습니다.
- 자료에 없는 내용은 문제로 내지 않습니다.

파일 이름은 "과목_단원_주제.xlsx" 로 해 주세요.
```
- 팝업에서 **문제 수**와 **학년**을 고르면 요청문의 해당 부분이 바뀐다. (제안)
- 확인 필요: AI 서비스마다 엑셀 파일을 직접 만들어 주는지가 다르다(표만 보여 주는 경우가 있음). 그런 경우를 위해 팝업에 "표로 나오면 빈 양식에 복사해 붙여넣으세요" 안내를 넣는다.

## 4. 올린 뒤 형식 검사
틀린 줄만 표시하고 나머지 문제는 살린다.
- 제목 줄이 양식과 다름 (열 순서가 바뀜) → 파일 전체 거부, 양식을 다시 받도록 안내
- 문제 또는 정답이 비어 있음 → 그 줄 제외
- 오답이 정답과 같음, 오답끼리 같음 → 그 줄 표시
- 같은 문제가 두 번 있음 → 뒤의 것 제외
- 문제·보기가 너무 김 (제안: 문제 80자, 보기 30자 초과) → 경고만
- 주관식 정답이 김 (제안: 15자 초과) → "학생이 입력하기 어려울 수 있어요" 경고

## 5. 검토·확정
- 미리보기에서 문제별로 **수정·삭제**. 정답이 눈에 띄게 표시된다.
- 주관식 문제에는 **인정할 다른 답**을 덧붙일 수 있다 (예: "서울" + "서울특별시"). (제안)
- [이 세트로 확정]을 눌러야 게임에 쓸 수 있다.
- 확정한 세트의 저장 위치 → 9절 확인 필요.

## 6. 문제 수와 배정
- 권장 문제 수: 학생 수 × 학생당 미션 수 이상 (10명 × 5개 → **30~50문제**). 요청문의 기본값은 30개.
- 문제가 모자라면 방을 만들 때 경고하고, 게임 중에는 다 쓴 뒤 **틀렸던 문제부터** 다시 낸다. (제안)
- 같은 학생에게 같은 판에서 같은 문제를 반복하지 않는다 (모자랄 때만 예외).
- 단말기는 "문제를 꺼내는 곳" 역할만 하고, 어떤 문제가 나올지는 무작위.

## 7. 오답 도움과 정답 보호
- 오답 뒤 5초 입력 잠금 (참고작 방식 유지).
- 양식에 힌트 칸이 없으므로 오답 도움은 자동으로 만든다. (제안)
  - 주관식: 2회 오답 → 글자 수, 3회 오답 → 첫 글자
  - 4지선다: 2회 오답 → 틀린 보기 하나 지우기
- 정답 보호: 학생 화면에는 **문제와 보기만** 보내고 채점은 서버 또는 선생님 화면이 한다. 방식은 기술 구성에 달려 있다 (확인 필요).

## 8. 학습 기록
- 문제별: 첫 시도 정답 / 재도전 해결 / 미해결, 풀이 시간, 오답 횟수.
- 학생에게: 점수 비교 없는 "나의 기록".
- 선생님에게: **많이 틀린 문제 순위**, 형식별 정답률, CSV 내려받기.

## 9. 확인 필요
1. ~~힌트·해설 칸 추가 여부~~ → **추가하지 않음 (2026-11-20 확정).** 양식은 퀴즈카트와 같은 5칸 그대로, 오답 도움은 7절의 자동 방식.
2. 확정한 문제 세트를 어디에 저장할 것인가? (선생님 브라우저 / 매번 엑셀을 다시 올림 / 서버 계정) — 기술 구성과 함께 결정.
