# 07. 새 맵 2개 컨셉 (초안 — 사용자 승인 전)

기준: 몬스터 체육관(2800×1900, 방 8개, 랜턴 8개, 미끄럼틀 1, 개구멍 1, 푹신 구역 1, 안개 중심 후보 3곳).
새 맵도 같은 데이터 칸(`rooms` `corridors` `doors` `furniture` `terminals` `spawn` `bell` `fog` `devices` `zones`)만으로 만든다. 코드(서버·규칙)는 안 바꾸고, 새 가구 그림만 `maprender.js` 에 추가한다.

## 한눈에 비교
| | 몬스터 체육관 | 달빛 대도서관 (제안) | 한밤의 학교 (제안) |
|---|---|---|---|
| 느낌 | 아늑한 한 건물 | 책장 미로, 숨바꼭질 | 운동장이 열린 큰 맵 |
| 크기 | 2800×1900 | 3000×2000 | 3600×2400 |
| 추천 인원 | 4~10명 | 4~10명 | 8명 이상 |
| 시야 | 방 안은 막히고 가운데는 뚫림 | 책장이 시야를 계속 가림 | 운동장은 활짝, 건물 안은 좁음 |
| 잠귀신 | 보통 | 숨기 좋아서 어려움(잠귀신이 불리) | 운동장에서 쫓기 쉬움(학생이 불리), 건물 안은 숨기 좋음 |
| 안개 후반 | 가운데 무대 근처 | 열람홀 한가운데 | 운동장 → 본관 안쪽으로 좁아짐 |

## 맵 A. 달빛 대도서관 (id `moon-library`)
**이야기**: 밤이 되면 책 속 이야기들이 깨어나 도서관을 돌아다닌다. 잠귀신은 "조용히 해야 하는 곳"이라 책장 사이를 소리 없이 다닌다.

**방 (8개)**
| 방 | 크기 느낌 | 특징 |
|---|---|---|
| 중앙 열람홀 | 가장 큼 | 가운데에 회의 종(안내 데스크 앞), 시작 자리. 긴 열람 책상이 길을 가름 |
| 책장 미로 (서가 A·B) | 큼 | 책장이 줄지어 서 있는 복도형. 가장 숨기 좋고 가장 헷갈림 |
| 어린이 책방 | 중간 | **푹신 구역**(쿠션·그림책 매트, 이동 느려짐). 작은 가구 많음 |
| 만화·웹툰방 | 작음 | 소파·빈백. 랜턴 1 |
| 컴퓨터실 | 중간 | 퀴즈 랜턴 2개(단말기 모양). 보급 가구 많음 |
| 북카페 | 중간 | 냉장고·자판기 등 보급 상자 가구 많음 |
| 고서 보관실 | 작음 | 금고·유리장. 입구가 좁음 → 잠귀신 길목 |
| 사서실·반납 창고 | 작음 | 책 카트, 반납함 |

**장치**
- **책 반납 미끄럼틀**: 북카페 반납구 → 고서 보관실 앞(긴 거리). 학생만(잠귀신 술래잡기) / 꿈도둑 모드에서는 모두.
- **책장 뒤 비밀 통로(개구멍 역할)**: 책장 한 칸이 밀리면서 입구. 출구 3곳 중 무작위(서가 B, 컴퓨터실 옆, 열람홀 구석).
- **푹신 구역**: 어린이 책방 바닥 (0.6배속).
- **"쉿! 조용히" 규칙은 넣지 않음** (규칙을 안 늘리고 분위기 글귀만: 로딩 TIP 에 "책장 사이는 길이 좁아요").

**안개 중심 후보 3곳**: 열람홀 가운데 / 북카페 / 어린이 책방. 후반 임시 랜턴은 열람홀·북카페 근처.
**랜턴 8개**: 컴퓨터실 2, 서가 A·B 각 1, 만화방 1, 어린이 책방 1, 고서 보관실 1, 열람홀 1.
**새 가구 그림**: 책장 높은 것·긴 열람 책상·책 카트·유리 진열장·빈백·사다리형 서가 (책장(`bookcase`)은 이미 있음).
**주의**: 책장이 많아 "보이지 않는데 막히는 곳"이 생기기 쉬움 → 만든 뒤 `tools/map-check.mjs` 로 막힘 사진 반드시 확인.

## 맵 B. 한밤의 학교 전체 (id `night-school`)
**이야기**: 모두 집에 간 한밤의 학교. 운동장에서 시작해 교실·복도·급식실을 거쳐 랜턴을 켠다. 안개가 줄어들수록 건물 안쪽으로 몰린다.

**구역**
| 구역 | 특징 |
|---|---|
| 운동장 (트랙·축구 골대·철봉) | 아주 넓고 탁 트임. 시작 자리 = 운동장 가운데. 철봉·벤치·스탠드가 숨는 곳 |
| 놀이터 | **푹신 구역 = 모래밭**(느려짐), 정글짐·그네, 미끄럼틀 장치 |
| 화단·연못 | 나무·화단이 시야를 조금 가림. 보급 상자(화분·창고) |
| 현관·신발장 | 건물 입구. 문 2개 |
| 본관 복도 | 긴 복도(벽 없는 `corridor`), 교실 3개가 붙음 |
| 교실 ×3 (3·4·5학년 느낌) | 책상 줄이 미로 역할. 랜턴 각 1 |
| 급식실 | 큰 식탁, 보급 많음 |
| 과학실·보건실 | 작은 방. 해골 모형·침대. 랜턴 1씩 |

**장치**
- **놀이터 미끄럼틀**: 놀이터 위 → 현관 앞. 운동장을 가로지르는 가장 긴 길.
- **담장 밑 개구멍**: 운동장 구석 담 → 출구 3곳(급식실 뒤, 화단, 과학실 뒷문). 학교 맵에서 가장 먼 거리를 이동.
- **모래밭**: 이동 0.6배속.
- 건물 안과 운동장 사이 문 2~3개만 두어 "건물 안으로 도망가기" 전략이 생김.

**안개 중심 후보 3곳**: 운동장 가운데 / 현관 / 급식실. 운동장 가운데가 중심이면 마지막엔 학생이 한 곳에 모여 긴박함(꿈도둑 모드 마지막 밤에 좋음). 임시 랜턴은 운동장 쪽 2곳.
**랜턴 8~10개** (확인 필요: 서버가 맵마다 랜턴 개수를 `terminals` 길이로 정하는지 — 맵이 크니 10개가 맞는지는 시험 플레이로 정함).
**새 가구 그림**: 철봉·그네·정글짐(있음)·축구 골대·스탠드·모래밭·나무·화단·교실 책상 줄·교탁·칠판·식탁·해골(있음)·보건실 침대.
**주의**: 3600×2400 은 큰 맵이라 휴대폰에서는 카메라 확대가 작아 보일 수 있음 → 확대 배율과 작은 지도(M)를 같이 확인. 로딩 시간·그림 양(캔버스 그리기)도 점검.

## 공통 작업 순서 (승인 후)
1. 맵 JSON 작성 (방·문·가구·랜턴·장치·안개 후보) → `tools/map-check.mjs` 검사·막힘 사진.
2. 새 가구 그림 추가 (`maprender.js`), 필요하면 가구 발 영역(`DRAWN`) 등록.
3. 맵 목록에 등록 → 선생님 페이지 "맵 고르기"와 로딩 화면 맵 이름/그림 적용 (맵별 로딩 TIP 추가).
4. 자동 시험(맵 검사 + 두 모드 봇 판) → 화면 확인(컴퓨터·휴대폰 크기).
5. HANDOFF·결정 기록 갱신, 커밋.

## 결정이 필요한 것 (질문)
1. 이름: "달빛 대도서관" / "한밤의 학교" 괜찮은지? (다른 후보: 책벌레 대도서관, 랜턴 초등학교)
2. 학교 맵 크기·인원: 큰 맵(8명 이상 추천)으로 가도 되는지, 아니면 몬스터 체육관 크기로 줄일지.
3. 둘 다 한 번에 만들지, 도서관 먼저 만들고 확인할지 (추천: 도서관 먼저 — 학교는 가구 그림이 더 많이 필요).

## 맵 C. 3층 학원 건물 (제안 이름: 한밤의 별빛 학원, id `star-academy`) — 테마 확정: 학원
**이야기**: 모두 집에 간 한밤의 학원 건물. 불 꺼진 3층짜리 학원을 오르내리며 랜턴을 켠다. (학원 가기 싫은 마음 + 밤의 학원 탐험이라 아이들이 좋아할 소재. 선생님·학생을 괴롭히는 장면은 넣지 않고 장난스럽게만.)

**핵심 아이디어 — "층 = 한 맵 안의 세 구역"** (서버·규칙을 거의 안 바꿈)
- 1·2·3층을 맵 좌표 위에 서로 멀리(약 1500칸 이상) 떨어뜨려 놓는다. 카메라는 내 층만 보이고, 다른 층 사람은 너무 멀어서 안 보인다(꿈도둑 모드의 시야 규칙도 그대로 통함).
- 층 이동은 지금 있는 장치(순간이동 `teleport`, 미끄럼틀 `slide`)로 만든다. 새 규칙 코드가 필요 없다.
- 각 층은 작게(약 1600×1000): 한 층은 방 4~5개 + 복도. 층이 좁아서 마주칠 일이 많고 빠르게 돈다.

**층 구성**
| 층 | 분위기 | 방·가구 | 랜턴 |
|---|---|---|---|
| 1층 | 로비·휴게층 | 접수 데스크(회의 종, 시작 자리), 휴게실(자판기·냉장고·간식 = 보급 많음), 신발장, 원장실 | 3 |
| 2층 | 교실층 | 영어·수학·과학 교실 3~4개(책상 줄이 미로), 자습실 | 3 |
| 3층 | 특별층·옥상 | 피아노·미술 교실(푹신 구역 = 미술실 매트), 컴퓨터실, 옥상 정원·별 관측대 | 2 |

**층 이동 장치 (이게 재미 포인트)**
| 장치 | 방향 | 누가 | 특징 |
|---|---|---|---|
| **계단** (층마다 양쪽 2곳) | 위아래 모두 | 모두 | 걸어 들어가면 바로 이동(짧은 대기), 가장 안전한 길 |
| **엘리베이터** (가운데 1대) | 1↔2↔3 | 학생만(잠귀신 술래잡기). 꿈도둑 모드는 모두 | 타고 내리는 데 1.5초 걸려 그 사이 움직일 수 없음. 쓰고 나면 재사용 대기 10초 |
| **미끄럼틀** (3층→1층) | 아래로만 | 학생 | 3층 옥상에서 1층 로비로 한 번에. 끝나면 잠깐 안전 |
| **개구멍** (책상 밑 / 사물함 뒤 비밀 통로) | 층 상관없이 3곳 중 무작위 | 학생 | 어느 층에 나올지 몰라 도망용 도박 |

→ 잠귀신 술래잡기에서는 "잠귀신은 계단만, 학생은 계단·엘리베이터·미끄럼틀·개구멍" 이라 도망갈 길이 많다. 대신 층이 좁다.

**잠 안개 (자기장) — 여기가 가장 큰 변경**
- 지금 안개는 동그란 빛 구역 하나라서 층이 셋인 맵에는 안 맞는다.
- 제안: **층 단위 안개**. 1단계는 모든 층이 안전 → 2단계에 3층이 어두워짐 → 3단계에 2층도 어두워짐 → 마지막에는 1층만 안전. 임시 랜턴(마지막 밤)은 1층에 2개.
- 필요한 일: 맵 데이터 `fog` 에 "층 영역 목록" 형식 추가, 서버 안개 계산(원 → 영역 판정)을 맵 종류에 따라 분기, 안개 예고 표시. **확인 필요** (서버 `FOG` 코드 구조를 보고 비용 확정). 어렵다면 대안: 안개를 쓰지 않고 "시간이 지나면 위층부터 문이 닫힌다(계단 막힘)" 로 단순화.

**화면 쪽 변경**
- 작은 지도(M)에 1·2·3층을 나란히 3칸으로 보여 주고 내 층 표시.
- 층 이동 때 층 이름 글씨("2층 교실층")와 짧은 흔들림 연출.
- 로딩 화면 맵 이름·TIP("엘리베이터는 학생만 탈 수 있어요").

**난이도·위험**
- 규칙을 거의 안 바꾸는 대신 **안개와 작은 지도**가 일을 만든다 (다른 두 맵보다 작업량 큼).
- 층 사이 이동이 너무 쉬우면 술래잡기가 안 끝남 → 쿨다운·잠귀신 제한으로 조절, 시험 플레이로 확정.
- 꿈도둑 모드: 층이 다르면 서로 안 보여 회의 전까지 증거가 적음 → 층 이동 소리 알림(예: "3층에서 엘리베이터 소리!")을 넣으면 재미있음 (선택).

**추천 순서**: ① 달빛 대도서관(규칙 변경 없음) → ② 한밤의 학교 → ③ 3층 학원 건물(안개 변경 포함). 3층 건물은 가장 마지막에 따로 설계서(06 형식)로 확정하고 만드는 것을 권함.

## 맵 D. 한밤의 놀이공원 (id `night-park`) — 2026-11-21 사용자 요청으로 제작
**이야기**: 문 닫은 한밤의 놀이공원. 놀이기구 불빛만 깜빡이는 공원을 돌아다니며 랜턴을 켠다.

**크기·구성**: 약 3200×2200, 야외 광장(가운데)이 넓게 열려 있고 둘레에 놀이기구 구역 8~9곳, 랜턴 8개. 가구 이름 앞글자 `pk`.

**이 맵만의 규칙 (새로 만든 것)**
| 장치 | 규칙 | 데이터 |
|---|---|---|
| **줄 서는 미끄럼틀** (2개: 대왕 미끄럼틀, 무지개 미끄럼틀) | 한 번에 한 명만 탄다. 타는 중이면 "앞사람이 타고 있어요. N초 뒤" 안내, 입구에 "사용 중" 표시. 타는 시간 3초 | 장치에 `solo: true` |
| **킥보드** (보급 상자) | 8초 동안 1.6배로 빨라짐. 이 맵 상자에서 더 자주 나옴. 잠귀신 술래잡기는 학생만, 꿈도둑 모드는 모두 | 아이템 `kickboard`, 맵 `items.extra` |
| **회전목마** | 올라타면 3초 동안 빙글 돌고 반대편에 내림. 여럿이 같이 탈 수 있고 잠귀신도 탈 수 있음(타는 동안은 서로 못 건드림) | `slide` 장치 + `style: 'carousel'` + 둥근 `path` |
| **유령의 집** | 안에 있으면 시야가 0.55배로 좁아짐 | 구역 `type: 'dark'` |
| 솜사탕 바닥(끈적) | 이동 0.6배 (기존 느려짐 구역) | 구역 `type: 'slow'` |

**나중에 정할 것**: 대관람차(전체 보기), 범퍼카(미끄러운 바닥), 킥보드로 벽에 부딪히면 멈춤.
