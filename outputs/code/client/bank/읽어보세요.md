# 문제 은행에 세트 더하는 방법

선생님 화면의 **[📚 문제 은행]** 버튼을 누르면 이 폴더의 세트 목록이 보입니다.

## 1. 엑셀 파일 만들기
- 선생님 화면에서 **[빈 양식 받기]** 로 받은 양식 그대로 씁니다.
- 첫 줄(제목)은 `문제 | 정답 | 오답1 | 오답2 | 오답3` 그대로 둡니다. 시트 이름도 `문제` 그대로.
- 정답만 쓰면 주관식, 오답까지 쓰면 고르는 문제가 됩니다.
- 파일 이름 예: `5학년_사회_2단원_인권.xlsx` (이름에 `/` `\` 는 쓰지 않습니다)

## 2. 이 폴더에 파일 넣기
`outputs/code/client/bank/` 폴더에 엑셀 파일을 넣습니다.

## 3. index.json 에 한 줄 더하기
`index.json` 의 `"sets"` 목록에 아래처럼 한 줄을 더합니다. (줄 사이에는 쉼표, 맨 마지막 줄 뒤에는 쉼표 없음)

```json
{ "grade": "5학년", "subject": "사회", "unit": "2단원", "title": "인권 존중과 정의로운 사회", "file": "5학년_사회_2단원_인권.xlsx" }
```

- `grade`(학년)와 `subject`(과목)는 목록 위의 고르기 상자에 쓰입니다. 같은 학년·과목은 글자를 똑같이 적어야 한 묶음이 됩니다.
- `unit`(단원)과 `title`(세트 이름)은 목록에 보이는 글자입니다.

## 4. 확인
`outputs/code` 폴더에서 `node server/test-bank.js` 를 실행하면 목록의 파일이 모두 있는지, 양식이 맞는지, 고쳐야 할 문제가 없는지 알려 줍니다.
그다음 커밋 → push → 서버에서 내려받기(pull)를 하면 실제 사이트에 보입니다. (서버를 껐다 켤 필요는 없습니다)
