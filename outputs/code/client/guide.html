🚦 이렇게 시작해요

  • 문제 넣기빈 양식을 받아 문제와 정답을 채워 엑셀로 올려요. 오답까지 쓰면 고르는 문제, 정답만 쓰면 주관식이에요. ‘AI 요청문 보기’로 문제 만들기를 도움받을 수 있어요.
  • 놀이 방법과 맵 고르기잠귀신 술래잡기 또는 꿈도둑을 찾아라, 맵 5곳 중 하나, 판 시간(5~15분)을 정해요.
  • 방 열기 → 게임 시작방 번호 4자리와 QR코드를 화면에 띄우면 학생들이 들어와요. 끝나면 퀴즈 리포트에서 문제별 정답률을 보고, 많이 틀린 문제만 다시 짚어 주세요.
  • 규칙 설명은 학생용 영상으로시작 전에 ‘학생용’ 탭의 영상을 화면에 틀어 주면 아이들이 규칙을 알 수 있어요.
