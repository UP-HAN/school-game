# 04 명세 — 그래픽 · 캐릭터

2026-11-20 사용자 확정. 기준: **참고작 이상 수준**. (참고작은 이미지 파일 없이 전부 코드로 그린 어두운 네온풍이다.)

## 1. 확정 (2026-11-20)
| 항목 | 결정 |
|---|---|
| 분위기 | **밝고 코믹한 만화풍.** 굵은 선, 선명한 색, 과장된 표정. 낮의 학교가 기본 |
| 제작 방식 | **혼합.** 움직이는 캐릭터는 코드로 그리고, 타이틀 화면·맵 배경·장식은 Codex 일러스트 |

| 캐릭터 선택 | **대기방에서 학생이 직접 고른다.** 색은 겹치지 않게 자동 배정 |

- 이 결정으로 `01-spec.md` 6절 5번("도형으로 먼저, 그림은 나중에")은 바뀐다: 맵도 처음부터 만화풍으로 꾸미고, 배경 일러스트는 맵 구조가 굳는 대로 입힌다.

### 1-1. 분위기 조정 (2026-11-20 사용자 요청: "조금만 더 무섭게")
- 대기방·첫 화면은 밝은 만화풍 그대로 두고, **게임 화면만 밤의 학교**로 바꿨다. 캐릭터는 코믹 그대로.
- 맵 전체에 푸르스름한 어둠을 입히고, 고장 난 단말기 화면만 초록빛으로 빛난다.
- 시야 밖은 거의 캄캄하다. 손전등 불빛이 가끔 살짝 깜빡인다.
- 술래 발밑에 붉은 기운이 일렁이고, 술래가 시야 안에 들어오면 화면 가장자리가 붉게 두근거린다 (가까울수록 빠르게).
- 장식: 방 구석의 거미줄, 바닥의 금, 복도의 수상한 발자국, 체육관 바닥의 할퀸 자국, 개구멍 속에서 가끔 깜빡이는 눈, 창고의 해골 모형.
- 수위: 피·시체 같은 표현은 쓰지 않는다. 초등학생이 웃으며 긴장할 정도까지만.

### 1-2. 가구 (2026-11-20 사용자 요청: "가구를 더 많이, 재밌게")
- 몬스터 체육관의 가구를 9개 → 54개로 늘렸다 (방마다 주제에 맞게: 무대의 드럼·스피커, 매점의 자판기·냉장고·식탁, 탈의실의 샤워 부스·세면대, 놀이방의 트램펄린·곰 인형·흔들 목마, 기구실의 러닝머신·짐볼, 복도의 음수대·신발장·트로피 진열장 등).
- 가구는 모두 지나갈 수 없는 장애물이다. 숨거나 돌아서 도망치는 데 쓸 수 있다. 가구를 넣은 뒤에도 모든 문·단말기·장치에 갈 수 있는지 맵 검사로 확인한다.

## 2. 캐릭터 (1차 8종)
| 묶음 | 캐릭터 |
|---|---|
| 사람 | 학생, 운동부 |
| 동물 | 고양이, 토끼, 공룡 |
| 몬스터·외계인 | 외눈이, 슬라임, 외계인 |

- 같은 캐릭터를 여러 학생이 골라도 된다. **색이 서로 다르기 때문**이다.
- 게임 중에는 이름 대신 **색 + 캐릭터**로 부른다 (예: "빨간 고양이", "보라 슬라임").
- 색 10가지: 빨강 · 주황 · 노랑 · 연두 · 초록 · 하늘 · 파랑 · 보라 · 분홍 · 갈색.
- 캐릭터 몸의 가장 넓은 부분이 플레이어 색이다 (사람은 옷, 동물·몬스터는 몸 전체).
- 코드로 그리는 이유: 10색 바꾸기, 걷기·눈 깜빡임·얼음 상태 같은 동작을 그림 추가 없이 만들 수 있다.
- 동작: 서 있기(숨쉬기), 걷기(발 구르기·통통 튀기), 눈 깜빡임, 얼음(얼음 덩어리에 갇힘). 나중에: 잡혔을 때 놀란 표정, 미끄럼틀 타기, 유령.
- 어떤 캐릭터를 골라도 **속도·크기 판정은 똑같다** (공정성).

## 3. 화면 스타일
- 굵은 남보라색 테두리 + 옆으로 살짝 밀린 그림자(만화책 느낌), 둥근 모서리, 크고 둥근 글씨.
- 버튼은 크게 (태블릿 손가락 기준 최소 48px).
- 술래·방해꾼이 가까이 오면 화면 가장자리가 살짝 붉어지는 식으로 긴장감만 더한다. (제안)

## 4. Codex 일러스트로 만들 것 (순서대로)
1. 타이틀 화면 배경 (게임 이름이 정해지면 로고 포함)
2. 몬스터 체육관 바닥·벽·장식 (미끄럼틀, 개구멍, 뜀틀, 농구대 등)
3. 문제 단말기, 긴급회의 버튼 같은 공통 소품
4. 승리·패배 화면 그림

- 그림 한 장에 1~2분이 걸리고 한 장씩 따로 만든다 (전역 규칙).
- 모든 그림에 같은 스타일 문구를 붙여 그림체를 맞춘다: "bright comic cartoon style, thick dark-purple outlines, flat vivid colors, top-down view" (제안)
