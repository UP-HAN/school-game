## 0. 프로그램 정보 (게임 현재 상태에서 확인한 값)

| 항목 | 내용 |
|---|---|

| 핵심 재미 3가지 | ① 맞히면 랜턴이 켜지고 새벽빛이 오른다 ② 잠귀신(술래)에게 잡히면 꿈에 빠지고 친구가 깨워 준다 ③ 누가 범인인지 모르는 "꿈도둑을 찾아라" + 모닥불 회의·투표 |
| 놀이 방법 | 2가지 (잠귀신 술래잡기 · 꿈도둑을 찾아라) |
| 맵 · 캐릭터 | 맵 5곳 · 캐릭터 8종류 |

| 기기 | 크롬북 · 태블릿 · 컴퓨터, 설치·회원가입 없음 |
| 수업 효과 | 끝나면 문제별 정답률(많이 틀린 문제부터) · 학생별 기록 · CSV 저장 |
| 문제 | 표에 바로 쓰기 · 엑셀 올리기 · [예시 문제] 30문제 · 문제 은행 |
| 주소 | 선생님 https://lab.ches.es.kr/lantern/teacher/ · 학생 https://lab.ches.es.kr/lantern/ · 안내 https://lab.ches.es.kr/lantern/guide.html |

퀴즈 카트와 다른 점 두 가지를 홍보에서 조심한다.

- **선생님 비밀번호**: 운영 서버는 방을 만들 때 비밀번호를 묻는다. 주소만 보내면 선생님이 방을 못 만든다. → DM에 비밀번호를 함께 넣는다 (아래 4번).

## 10. 올리는 순서 (사람이 하는 일)

1. 인스타 앱: 설정 → 메시지 및 스토리 답장 → 메시지 컨트롤 → **메시지 액세스 허용** 켜기
2. 릴스 올리기: 세로 영상 + 커버(카메라 롤에서 추가) + 2절 본문. 영상에 음악이 들어 있으니 인스타 음악은 넣지 않는다
3. 올린 직후 3절 고정 댓글 달고 고정
4. 리틀리(litt.ly) → 마케팅 → 인스타 DM 자동 발송 → 게시물 선택 · 키워드 (포함) · 5절 자동 답글 · 4절 DM(비밀번호 ○○○○ 채우기) · 링크 버튼 5. 다른 계정으로 "랜턴" 댓글을 달아 DM·답글이 오는지 확인
6. 스토리에 릴스 공유 + 링크 스티커(guide.html)
7. 카톡·밴드에는 6절 메시지 (가로 영상 첨부 가능)
