# 05 명세 — 방해꾼 찾기 모드 (어몽어스 방식)

작성 2026-11-20 · 상태: **초안, 사용자 승인 전**
기준: `HANDOFF.md` 3-3절(참고작 규칙). 숫자는 참고작 값을 기본으로 했다.
"**가정**" 표시 = 참고작에서 확인하지 못했거나 애매해서 기획자가 정한 기본값. 사용자가 바꿀 수 있다 (9절에 모아 둠).

---

## 0. 한눈에 보기
- 학생 중 몰래 정해진 **방해꾼**(1~2명)이 학생을 **얼리고**, 정전·문 잠금·위장으로 방해한다.
- 학생은 단말기 문제를 풀어 **복구율 100%** 를 만들거나, **회의·투표**로 방해꾼을 모두 찾아내면 이긴다.
- **얼려진 학생은 탈락하지 않고 "유령"** 이 되어 문제를 계속 푼다 (학습에서 빠지는 학생이 없게 하는 핵심 규칙).
- 회의에는 채팅이 없다. 화면에는 캐릭터 카드만 나오고, **토론은 교실에서 말로** 한다.

용어 (처음 나오는 말 풀이)
| 말 | 뜻 |
|---|---|
| 방해꾼 | 학생인 척하는 상대 팀. 화면에는 자기 자신과 동료 방해꾼만 "방해꾼"으로 보인다 |
| 얼리기 | 방해꾼이 가까운 학생을 얼리는 것. 얼려진 학생은 유령이 된다 |
| 유령 | 얼려졌거나 투표로 제외된 사람. 움직이고 문제는 풀지만, 살아 있는 사람에게 안 보이고 투표는 못 한다 |
| 얼음 흔적 | 학생이 얼려진 자리에 남는 얼음 조각상. 가까이서 신고할 수 있다 |
| 신고 | 얼음 흔적을 발견하고 회의를 여는 것 |
| 긴급회의 | 맵 가운데 버튼을 눌러 회의를 여는 것 |
| 쿨타임 | 한 번 쓰고 나서 다시 쓸 수 있을 때까지 기다리는 시간 |
| 시야 | 내 캐릭터 둘레로 보이는 동그란 범위 |

## 1. 역할과 인원

### 1-1. 역할 이름 통일 (결정)
지금 코드는 역할을 `'student'`(학생) · `'chaser'`(술래) 두 값으로 쓰고, 맵 파일의 장치 `who.impostor` 에는 `'saboteur'` 라고 적혀 있어 서로 맞지 않는다.

- **코드 안의 역할 값은 두 모드 모두 `'student'` · `'chaser'` 두 개로 통일한다.** `'chaser'` 는 "상대 팀" 칸이라는 뜻이고, 화면에 보이는 이름은 모드에 따라 `MODES[].chaser`(얼음땡 "술래", 방해꾼 찾기 "방해꾼")로 바꿔 보여 준다.
  - 이유: 이미 `goalOf`(복구율 목표), `chaserCount`, 화면 HUD, 학습 기록이 `'chaser'` 로 짜여 있어 새 값을 만들면 고칠 곳이 많아진다.
- 맵 파일 `maps/monster-gym.json` 의 `"impostor": ["student", "saboteur"]` 를 `["student", "chaser"]` 로 고친다 (장치 2개).
- 맵 검사(`shared/mapgrid.js` `validateMap`)에 "who 에 `student`·`chaser` 말고 다른 값이 있으면 경고" 를 넣는다.
- 01 명세 3절의 예시 JSON 도 같이 고친다.

### 1-2. 상태 값 (사람마다)
역할(`role`)과 별도로 **살아 있음/유령** 상태를 둔다. 얼음땡의 `frozen`(제자리에 얼음)과는 뜻이 달라서 **새 칸 `ghost` 를 쓴다** (`frozen` 은 방해꾼 찾기에서 항상 `false`).

| 칸 | 값 | 뜻 |
|---|---|---|
| `role` | `'student'` / `'chaser'` | 학생 / 방해꾼 |
| `ghost` | `true`/`false` | 유령인가 (얼려졌거나 제외됨) |
| `ghostKnown` | `true`/`false` | 다른 사람들이 그 사실을 아는가. 회의가 열리면 그때까지의 유령이 모두 `true` 가 된다. 투표로 제외되면 바로 `true` |
| `ejected` | `true`/`false` | 투표로 제외되었나 (유령이 된 이유 구분용) |
| `usedButton` | `true`/`false` | 긴급회의 버튼을 이미 썼나 (1인 1회) |
| `disguise` | `null` 또는 `{ color, character, until }` | 위장 중인 모습 |
| `disguiseLeft` | 0~2 | 남은 위장 횟수 |
| `tagReadyAt` | 시각 | 다음에 얼릴 수 있는 때 (얼음땡의 잡기 칸을 그대로 쓴다) |

### 1-3. 인원별 방해꾼 수
- 추천: **7명까지 1명, 8명부터 2명** (이미 `recommendChasers` 에 있음, 결정 완료).
- 선생님이 1~3명으로 직접 정할 수 있다 (이미 있음).
- **새 제한 (가정)**: 방해꾼 찾기에서는 "시작하자마자 방해꾼 승리"가 되지 않도록 **방해꾼 수 ≤ (인원 − 1) ÷ 2 (내림)** 로 줄인다. 예) 4명이면 최대 1명, 6명이면 최대 2명, 7명이면 최대 3명. `chaserCount` 에서 모드가 `impostor` 일 때만 적용.

### 1-4. 선생님이 방해꾼 직접 지정 (참고작 규칙)
- 대기방 설정에 **"방해꾼 직접 고르기"** 를 둔다. 학생 목록에서 체크한다.
- **학생 화면에는 절대 보내지 않는다.** 지금 `roomView` 는 `settings` 를 모두에게 보내므로, 지정 목록은 `settings` 에 넣지 않고 `room.pickedChasers`(서버만) 에 두고 **선생님에게만** 보낸다.
- 시작할 때 규칙 (가정):
  1. 지정한 학생이 있으면 **그 학생들만** 방해꾼이 된다 (자동/숫자 설정은 무시). 단 1-3절 제한보다 많으면 시작을 막고 "방해꾼이 너무 많아요" 안내.
  2. 지정한 학생이 나갔으면 목록에서 빠진다. 남은 지정자가 0명이면 자동 배정으로 돌아간다.
  3. 아무도 지정하지 않으면 지금처럼 무작위.
- 선생님 화면은 TV 에 띄울 수 있으므로 지정 체크 칸은 **"방해꾼 고르기 열기" 버튼을 눌러야 펼쳐진다**.

### 1-5. 도중 입장 (확정)
- 게임 도중 들어온 학생은 **학생 역할, 살아 있는 상태**로 시작한다 (3초 보호, `TAG.joinProtectMs` 재사용).
- 회의 중에 들어오면 회의 화면을 보지만 **그 회의에서는 투표하지 않는다** (가정). 회의가 끝나면 시작 자리에 나타난다.
- 같은 이름 재입장(이어 하기)은 역할·유령 상태를 그대로 이어 받는다.

## 2. 게임 규칙

### 2-1. 시작
- 선생님 "게임 시작" → 역할 배정 → 모두 시작 자리(중앙 복도) 둘레에 선다.
- 학생 화면에 역할 안내: "너는 학생!" / "너는 방해꾼! (동료: 파란 토끼)". 3초쯤 보여 준다 (기존 `showIntro` 재사용).
- 방해꾼끼리는 서로를 안다 (가정, 어몽어스와 같음). 화면에서 동료 머리 위에 작은 빨간 뿔 표시.
- 제한 시간: 얼음땡과 같은 설정 (5~15분, 기본 10분). 회의 중에는 시계가 멈춘다.

### 2-2. 미션 (얼음땡 구조 그대로)
- 학생: 지금과 똑같다. 단말기 앞에서 문제 열기 → 서버 채점 → 맞으면 복구율 상승. 같은 단말기는 사람마다 한 번, 학생당 문제 수는 선생님 설정(3~8, 기본 5).
- **유령 학생도 문제를 풀 수 있고 복구율이 오른다.** (참고작 핵심 규칙)
- 복구율 목표 = 학생 역할 수(유령 포함) × 학생당 문제 수. 방해꾼은 목표에 안 들어간다 (지금 `goalOf` 그대로).
- **방해꾼의 가짜 미션**: 방해꾼도 단말기에서 **진짜 문제를 받아 푼다** (가정. 방해꾼도 공부하게 하려는 것). 채점·오답 도움·잠금은 똑같지만
  - 맞혀도 `room.solvedTotal`(복구율)은 오르지 않는다.
  - 자기 화면에는 "내 미션 3/5" 로 학생과 똑같이 보인다 (정체가 드러나지 않게).
  - 학습 기록에는 남고, 기록에 `role: 'chaser'` 가 붙는다.
- 다른 학생의 "푼 문제 수"는 방해꾼 찾기에서 **학생 화면에 보내지 않는다** (방해꾼의 가짜 미션이 수로 들키지 않게). 전체 복구율만 보인다. 선생님은 모두 본다.

### 2-3. 얼리기 (방해꾼 전용)
| 항목 | 값 | 상수 |
|---|---|---|
| 닿는 거리 | 100 | `IMPOSTOR.freezeReach` |
| 첫 사용 가능 | 시작 15초 뒤 | `IMPOSTOR.freezeGraceMs` |
| 쿨타임 | 25초 | `IMPOSTOR.freezeCooldownMs` |
| 회의가 끝난 뒤 | 다시 15초 기다림 (가정) | `IMPOSTOR.freezeAfterMeetingMs` |

- 대상: 가장 가까운 **살아 있는 학생**. 방해꾼·유령·보호 중(도중 입장·장치 타는 중·도착 1초)인 사람은 안 된다.
- 회의 중, 게임이 끝난 뒤에는 못 쓴다.
- 얼려지면
  1. 그 학생은 **유령**(`ghost: true`, `ghostKnown: false`)이 된다. 열려 있던 문제 창은 닫히고 "못 풂"으로 기록된다 (얼음땡과 같음).
  2. 그 자리에 **얼음 흔적**이 남는다 (`room.marks` 에 추가: 얼려진 사람 id·위치·색·캐릭터).
  3. 유령은 그 자리에서 바로 움직일 수 있다.
- 헛손질(근처에 대상 없음)은 0.8초 쉬기 (얼음땡과 같음).

### 2-4. 유령
- 살아 있는 사람에게는 **보이지 않는다**. 유령은 다른 유령과 살아 있는 사람을 모두 본다.
- 문제 풀기 가능 (학생 유령이면 복구율에 들어감). 장치(미끄럼틀·개구멍)도 탈 수 있다 (가정).
- 벽은 그대로 막힌다 (가정. 충돌 코드를 바꾸지 않으려고).
- 할 수 없는 것: 얼리기·방해·신고·긴급회의·투표. 얼려질 수도 없다.
- 정전의 영향을 받지 않는다 (시야 그대로).
- 제외된 방해꾼도 유령이 된다. 방해 능력은 모두 사라지고, 가짜 미션만 계속 풀 수 있다 (가정).
- 화면: 반투명 + 위아래로 둥실둥실, 머리에 작은 유령 꼬리. 화면 위에 "유령이 되었어요 — 미션을 계속 풀어 학교를 도와주세요! (회의 때는 말하지 않기)" 안내.

### 2-5. 방해 (방해꾼 전용, F 키 또는 "방해" 버튼 → 3개 중 선택)
| 방해 | 효과 | 지속 | 쿨타임 | 상수 |
|---|---|---|---|---|
| 1 정전 | 살아 있는 학생의 시야가 35% 로 줄어든다 | 8초 | 40초 | `blackoutMs` · `blackoutVision` · `blackoutCooldownMs` |
| 2 문 잠금 | 방해꾼에게 가장 가까운 "잠글 수 있는 문" 1개를 막는다 (가정) | 7초 | 45초 | `lockMs` · `lockCooldownMs` · `lockReach` |
| 3 위장 | 다른 살아 있는 학생 한 명의 모습(색·캐릭터)으로 바뀐다 | 10초 | 게임당 2회 | `disguiseMs` · `disguisePerGame` |

- 정전·문 잠금의 쿨타임은 **방해꾼 팀이 같이 쓴다** (가정. 방해꾼 2명이 연달아 써서 계속 정전이 되지 않게). 위장 횟수는 **사람마다** 2회.
- 시작 뒤 15초 동안은 방해도 못 쓴다 (`IMPOSTOR.sabotageGraceMs`, 가정).
- 정전과 문 잠금은 동시에 걸릴 수 있다. 같은 종류는 겹치지 않는다 (쿨타임이 지속보다 길다).
- 회의가 시작되면 정전·문 잠금·위장이 모두 즉시 풀린다. 쿨타임은 계속 흐른다 (가정).
- **정전**: 방해꾼·유령·선생님 화면은 그대로. 화면 가장자리에서 형광등이 "깜빡깜빡" 꺼지는 연출 후 시야가 작아진다. 단말기 초록 불빛은 그대로 보인다 (찾아갈 수 있게).
- **문 잠금**: 거리 `lockReach`(300) 안에 잠글 문이 없으면 "근처에 잠글 문이 없어요" 안내, 쿨타임은 쓰지 않는다. 잠긴 문 칸은 벽처럼 막힌다. **이미 그 문 칸에 서 있던 사람은 빠져나올 수 있다** (끼임 방지: 지금 위치가 잠긴 문과 겹치면 이동을 허용). 맵 파일의 `doors[].lockable` 을 쓴다 (몬스터 체육관은 7개).
- **위장**: 대상은 서버가 살아 있는 학생 중 무작위로 고른다 (가정. 태블릿에서 고르기 쉽게). 다른 사람의 화면과 회의 카드 목록에는 위장한 모습이 보인다. 위장 중에 얼리기 가능 (누명 씌우기 전략). 같은 모습이 둘 보일 수 있다.

### 2-6. 신고와 긴급회의
| 항목 | 값 | 상수 |
|---|---|---|
| 신고 거리 (얼음 흔적에서) | 110 | `IMPOSTOR.reportReach` |
| 긴급회의 버튼 거리 | 90 (가정) | `IMPOSTOR.buttonReach` |
| 긴급회의 횟수 (게임 전체) | 기본 3회, 선생님 설정 0~5 | `IMPOSTOR.meetingsDefault`, `MEETINGS` |
| 사람당 긴급회의 | 1회 | (규칙) |
| 버튼을 못 쓰는 때 | 시작 뒤 15초, 회의 끝난 뒤 15초 (가정) | `IMPOSTOR.buttonGraceMs` |

- **신고(R)**: 살아 있는 사람이면 누구나 (방해꾼도 — 자기가 얼린 흔적을 먼저 신고하는 전략 가능). 유령은 못 한다.
- **긴급회의**: 참고작대로 **살아 있는 학생만**. 방해꾼 화면에도 버튼은 보이지만 누르면 "지금은 누를 수 없어요" 만 뜬다 (가정. 버튼이 아예 없으면 정체가 드러남). 누가 열었는지는 회의 화면에 **표시하지 않는다** (가정. 학생만 누를 수 있으므로 표시하면 그 사람이 학생임이 드러난다).
- 남은 긴급회의 횟수가 0이거나 이미 한 번 썼으면 버튼이 회색.
- 회의가 열리면 **모든 얼음 흔적은 사라진다**.

### 2-7. 회의 → 토론 → 투표 → 결과
| 단계 | 시간 | 상수 | 화면 |
|---|---|---|---|
| 시작 알림 | 2초 | `IMPOSTOR.meetingIntroMs` (가정) | "신고! 얼음 흔적 발견" 또는 "긴급회의!" 큰 글씨 |
| 토론 | 25초 | `IMPOSTOR.discussMs` | 캐릭터 카드만. 교실에서 말로 토론 |
| 투표 | 15초 | `IMPOSTOR.voteMs` | 카드 누르기 / "건너뛰기" |
| 결과 | 3.5초 | `IMPOSTOR.resultMs` | 제외된 사람 또는 "아무도 제외되지 않았어요" |

- 회의 중에는 **게임 시계가 멈춘다**. 아무도 못 움직이고, 열려 있던 문제 창은 닫힌다. 이때 문제는 **기록하지 않고 닫는다**(중단). 다음에 다시 나올 수 있게 "못 푼 문제" 목록에는 넣는다 (가정. 회의 때문에 "못 풂"이 쌓이지 않게).
- 회의 카드: 모든 사람의 "색+캐릭터" (위장은 풀린 진짜 모습). 유령(그때까지 얼려진 사람 포함)은 회색 카드 + 얼음 표시, 누를 수 없다. 신고면 "발견된 얼음: 빨간 고양이" 를 위에 표시하고 신고자 카드에 확성기 표시 (신고는 누구나 하므로 표시해도 정체가 드러나지 않는다).
- 이름은 회의 카드에도 쓰지 않는다 (게임 중에는 색으로 부르는 규칙). 카드 크기는 태블릿 손가락 기준 최소 48px.
- **투표 규칙**
  1. 투표할 수 있는 사람 = 회의가 시작될 때 살아 있고 연결된 사람 (도중 입장자는 다음 회의부터).
  2. 한 사람 한 표, **바꿀 수 없다** (가정). 자기 자신에게는 못 낸다 (화면에서 막고, 서버도 무효 처리).
  3. 투표하지 않은 사람은 아무 쪽에도 세지 않는다 (건너뛰기와 다름).
  4. 투표할 수 있는 사람이 모두 내면 투표 시간을 기다리지 않고 바로 결과로 간다 (가정).
  5. 누가 투표를 끝냈는지는 카드에 체크 표시로 보인다. **누가 누구를 찍었는지는 공개하지 않는다** (가정. 학생 사이 감정 다툼 줄이기). 결과에는 카드별 득표 수만.
- **제외 규칙 (참고작)**: 가장 많이 받은 사람이 **한 명뿐**이고, 그 표가 **건너뛰기 표보다 많아야** 제외. 동점이면 아무도 제외 안 됨.
- 제외된 사람은 유령이 된다 (`ejected: true`, `ghostKnown: true`).
- **제외자 역할 공개**: 선생님 설정 "제외된 사람의 정체 공개" 켜기/끄기 (기본 **켜기**, 가정). 켜면 "빨간 고양이는 방해꾼이었어요!" / "…방해꾼이 아니었어요". 끄면 "빨간 고양이가 제외되었어요".
- 결과가 끝나면 승패 확인 → 이어 하면 **모두 시작 자리로 돌아간다** (가정, 어몽어스와 같음). 시계 다시 흐름.
- **선생님 회의 조작** (가정, 교실 토론용): "토론 15초 더"(`IMPOSTOR.extendMs`, 회의당 2번까지), "바로 투표로". 토론을 말로 하므로 시간이 모자랄 때를 대비한다.

### 2-8. 승패 (참고작 4가지, 위에서부터 확인)
| 순서 | 조건 | 이긴 편 | `over.reason` |
|---|---|---|---|
| ① | 살아 있는 방해꾼 0명 | 학생 | `'all_found'` |
| ② | 복구율 100% | 학생 | `'restored'` |
| ③ | 살아 있는 학생 수 ≤ 살아 있는 방해꾼 수 | 방해꾼 | `'outnumbered'` |
| ④ | 시간 끝 | 방해꾼 | `'time_up'` |

- `over.winner` 값은 얼음땡과 같이 `'students'` / `'chasers'`.
- 확인하는 때: 얼리기 직후, 투표 결과 직후, 문제 정답 직후, 사람이 나가거나 정리된 직후(60초 끊김 정리 포함), 매 틱(시간).
- "살아 있는" = 유령이 아닌 사람. 연결이 잠깐 끊긴 사람도 정리되기 전까지는 살아 있는 것으로 센다.
- 얼리기로 ③이 되면 회의 없이 바로 끝난다.
- 게임이 끝나면 **모든 사람의 역할을 공개**한다 (결과 화면에 "방해꾼은 파란 토끼, 노란 공룡이었어요").

## 4. 서버

### 4-1. 방(`room`)에 새로 생기는 값
| 칸 | 뜻 |
|---|---|
| `settings.meetings` | 긴급회의 총 횟수 (0~5, 기본 3). 모두에게 보내도 됨 |
| `settings.reveal` | 제외자 정체 공개 (true/false, 기본 true) |
| `pickedChasers` | 선생님이 지정한 방해꾼 id 목록. **선생님에게만** 보냄 |
| `meetingsLeft` | 남은 긴급회의 횟수 |
| `marks` | 얼음 흔적 목록 `[{ id, x, y, color, character }]` |
| `sabo` | `{ blackoutUntil, lock: { door, until } \| null, readyAt: { blackout, lock } }` |
| `meeting` | 회의 중이 아니면 `null`. 회의 중이면 아래 |
| `buttonReadyAt` | 긴급회의 버튼을 다시 쓸 수 있는 때 |
| `pausedLeft` | 회의 동안 멈춰 둔 남은 게임 시간 (ms) |

`room.meeting`:
```
{
  stage: 'intro' | 'discuss' | 'vote' | 'result',
  stageEndsAt,            // 지금 단계가 끝나는 때
  reason: 'report' | 'button',
  reporter,               // 신고한 사람 id (긴급회의면 null — 화면에 안 보냄)
  found,                  // 신고된 얼음 흔적의 주인 id
  voters: Set,            // 투표할 수 있는 사람
  votes: Map,             // 투표한 사람 id → 찍은 id 또는 'skip' (서버만)
  extended,               // 선생님이 토론을 늘린 횟수
  result: null | { ejected: id|null, tie, counts: {id: n, skip: n}, role?: 'student'|'chaser' }
}
```
- 회의 단계는 `stateTick`(초당 10회) 안에서 시각을 보고 넘긴다 (타이머를 따로 만들지 않는다).

### 4-2. 메시지 종류
**학생 화면 → 서버**
| `t` | 내용 | 누가 | 비고 |
|---|---|---|---|
| `tag` | (없음) | 살아 있는 방해꾼 | 얼리기. 기존 메시지 재사용 |
| `sabotage` | `{ kind: 'blackout' \| 'lock' \| 'disguise' }` | 살아 있는 방해꾼 | |
| `alarm` | `{ mark: id }` | 살아 있는 사람 | 얼음 흔적 신고. **`report` 는 이미 학습 기록 요청 이름이라 쓰지 않는다** |
| `emergency` | (없음) | 살아 있는 학생 | 긴급회의 버튼 |
| `vote` | `{ target: id \| 'skip' }` | 투표할 수 있는 사람 | 투표 단계에서만 |
| `open` `answer` `closeq` `use` `pos` | 기존 그대로 | | 회의 중에는 모두 무시 (`pos` 는 `fix` 로 되돌림) |

**선생님 화면 → 서버**
| `t` | 내용 | 비고 |
|---|---|---|
| `settings` | 기존 + `meetings`(0~5), `reveal`(true/false) | 대기방에서만 |

| `meetingCtl` | `{ action: 'extend' \| 'vote' }` | 토론 단계에서만 |

**서버 → 화면**
| `t` | 누구에게 | 내용 |
|---|---|---|
| `room` | 사람마다 다르게 (4-3절) | 기존 + `meeting`(아래), `sabo`(`blackoutMs`, `lockedDoor`, `lockMs`), `marks`, `meetingsLeft` |
| `me` | 본인 | 기존 + `ghost`, `mates`(동료 방해꾼 id, 방해꾼만), `freezeMs`, `saboMs: { blackout, lock }`, `disguiseLeft`, `usedButton`, `buttonMs` |
| `state` | 사람마다 다르게 | 기존 `[id, x, y, f, m]`. 살아 있는 사람에게는 유령 위치를 빼고 보냄 |
| `event` | 정해진 사람만 | `freeze`(얼린 방해꾼들 + 얼려진 사람에게만), `meeting`(모두, 회의 시작 연출), `eject`(모두), `blackout`·`lock`(모두, 연출용, **누가 썼는지는 안 넣음**) |
| `picked` | 선생님만 | `{ ids }` |
| `closeq` | 본인 | 기존. 얼려질 때·회의 시작 때 |

`room` 안의 `meeting` (화면용):
```
{ stage, msLeft, reason, reporter?, found?, voted: [투표 끝낸 id], myVote?, canVote,
  cards: [{ id, color, character, ghost, ejected }],
  result?: { ejected, tie, counts, role? } }
```
- `votes`(누가 누구를) 는 어느 화면에도 보내지 않는다. `myVote` 는 본인 것만.

### 4-3. 정체 숨기기 (중요 — 지금 코드의 빈틈)
지금 `roomView` 는 **모든 사람의 `role` 을 모든 화면에** 보낸다. 얼음땡은 술래가 공개라 괜찮지만, 방해꾼 찾기에서는 개발자 도구로 정체를 볼 수 있다. 그래서 방해꾼 찾기에서는 받는 사람마다 보이는 값을 다르게 만든다 (`viewFor(room, 받는사람)`).

| 값 | 선생님 | 방해꾼 | 살아 있는 학생 | 유령 |
|---|---|---|---|---|
| 남의 `role` | 보냄 (화면에서 "역할 보기"를 눌러야 표시) | 동료 방해꾼만 | 안 보냄 | 안 보냄 (가정. 유령이 교실에서 말해 버리는 것을 막기 위해) |
| 남의 `ghost` | 보냄 | `ghostKnown` 인 것 + 자기가 얼린 사람 (가정: 방해꾼끼리는 모두) | `ghostKnown` 인 것만 | 모두 |
| 유령의 위치 (`room`·`state`) | 보냄 | 보냄 (가정) | 안 보냄 | 보냄 |
| 남의 `solved` | 보냄 | 안 보냄 | 안 보냄 | 안 보냄 |
| 위장 | 진짜 모습 + 위장 표시 | 진짜 모습 + 위장 표시 | 위장한 모습 | 위장한 모습 |
| `pickedChasers` | 보냄 (`picked`) | 안 보냄 | 안 보냄 | 안 보냄 |

- 게임이 끝나면(`room.over`) 모두에게 모든 값을 보낸다.
- 남은 빈틈 (받아들임): 위장 중에도 사람 id 는 그대로라 개발자 도구로는 구분 가능. 위치는 시야 밖이어도 보낸다 (지금과 같은 방식, 학생 대상이라 받아들임).

### 4-4. 서버 처리 순서 요약
- `start`: `mode_not_ready` 제거 → 방해꾼 뽑기(지정 우선) → `initPlayerGame` → `meetingsLeft = settings.meetings`, `marks = []`, `sabo` 초기화, `buttonReadyAt = now + buttonGraceMs`.
- `tag`(방해꾼 찾기): 조건 확인 → 대상 유령으로 → 흔적 추가 → 대상 문제 창 닫기 → `event freeze` 를 정해진 사람에게 → 승패 확인 → 보내기.
- `alarm`/`emergency` → `startMeeting(room, reason, ...)`: 남은 시간 멈춤, 모든 문제 창 `'cancel'` 로 닫기, 방해 효과 풀기, 위장 풀기, 흔적 지우기, `ghostKnown` 갱신, 투표자 정하기, `stage: 'intro'`.
- `stateTick`: 회의 단계 넘기기 (intro → discuss → vote → result → 끝). 투표자 전원 투표하면 vote → result 바로.
- `endMeeting`: 결과 적용(유령으로) → 승패 확인 → 아니면 모두 시작 자리로, `endsAt = now + pausedLeft`, `tagReadyAt = now + freezeAfterMeetingMs`, `buttonReadyAt = now + buttonGraceMs`.
- 60초 끊김 정리로 사람이 빠질 때: 투표자 목록에서도 빼고, 승패 확인.
- 선생님 "게임 끝내기": 지금과 같이 대기방으로 (회의 중이어도).

### 4-5. 서버 구현에서 정한 세부 (2026-11-20, 4-2절 계약에 덧붙임 — 이름·모양은 4-2절 그대로)
- **`room.players[]` 항목 (방해꾼 찾기 게임 중)**: `id, name, color, character, connected, frozen(항상 false), protMs` + 받는 사람에 따라 `x, y`(유령이면 살아 있는 학생에게는 빠짐), `role`(본인·동료 방해꾼·선생님만), `ghost, ejected`(알 수 있을 때만, 모르면 칸 자체가 없음), `solved`(본인·선생님만), `disguise: { color, character, ms }`(선생님·방해꾼에게만. 다른 사람에게는 `color`·`character` 가 위장한 모습으로 바뀌어 감).
- **`room.meeting`** 에 `extended`(선생님이 토론을 늘린 횟수, 0~2) 를 더 보낸다. `canVote` = 이번 회의 투표자인가 (투표를 마쳐도 true, 마쳤는지는 `myVote`·`voted` 로 안다). `reporter`·`found` 는 신고 회의일 때만 있다. `result.counts` 는 `{ 사람id: 표 수, skip: 표 수 }` (표를 받은 사람만).
- **`event`**: `freeze` 는 `{ by, id, x, y }`, `meeting` 은 `{ reason, reporter?, found? }`, `eject` 는 `{ id, role? }`(role 은 정체 공개 켜짐일 때만), `blackout` 은 `{ ms }`, `lock` 은 `{ door, ms }`. 유령이 장치를 타는 `ride` 는 선생님·방해꾼·유령에게만 보낸다.
- **회의가 끝나면** 서버가 각 학생에게 `fix`(새 시작 자리)를 보낸다.
- **`picked`** 는 선생님이 다시 접속할 때, 지정한 학생이 나갈 때도 보낸다.
- **거부할 때 보내는 `error` 코드** (화면 안내용, `msg` 에 한국어 문장이 같이 감):
  - `sabotage`: `too_early`(시작 뒤 대기) · `sabo_cooldown` · `no_door`(300 안에 잠글 문 없음, 쿨타임 안 씀) · `already_disguised` · `no_disguise`(횟수 다 씀) · `no_target`
  - `alarm`: `ghost` · `no_mark` · `too_far`
  - `emergency`: 확인 순서대로 `ghost` · `not_now`(방해꾼) · `button_used` · `no_meetings` · `too_far` · `too_early`
  - `vote`: `not_voting` · `cannot_vote`(유령·도중 입장자) · `already_voted` · `bad_vote`(자기 자신·유령·없는 사람)
  - `start`: `too_many_chasers`(직접 고른 방해꾼이 1-3절 제한보다 많음)
  - 얼리기(`tag`)는 거부해도 메시지가 없다 (헛손질이면 `me` 의 `freezeMs` 가 0.8초로 바뀜). 회의 중 `open`·`tag`·`sabotage`·`use` 도 아무 답이 없다.
- 위장은 위장 중에 다시 쓸 수 없다 (끝난 뒤 다시 가능, 사람마다 2회).
- 학습 기록 한 줄에 `role`·`ghost` 가 붙는다 (얼음땡 기록에도 `role` 이 붙고 `ghost` 는 false).
- 시험용: 환경변수 `TEST_OVERRIDES` 로 `IMPOSTOR` 숫자·게임 1분 길이·끊김 정리 시간을 줄일 수 있다 (자동 시험만 씀).

### 5-2. 맵 위에 그리는 것
- **얼음 흔적**: 얼린 사람 색의 캐릭터가 얼음 덩어리에 갇힌 모습(얼음땡 얼음 그림 재사용) + 위에 "!" 깜빡임. 시야 안에서만 보임.
- **유령**: 반투명(투명도 50%) + 둥실둥실. 유령 본인·다른 유령에게만 보임.
- **동료 방해꾼 표시**: 방해꾼 화면에서만, 동료 머리 위 작은 빨간 뿔. 이름표 "방해꾼"은 **자기와 동료에게만**. (얼음땡의 모두에게 보이는 "술래" 이름표는 이 모드에서 안 씀)
- **잠긴 문**: 문 자리에 빨간 철창 + 자물쇠, 남은 시간 원. 맵 그림은 미리 그려 두므로(`renderMap`) 그 위에 덧그린다.
- **정전**: 살아 있는 학생 시야 원을 340 → 119 로 0.4초에 걸쳐 줄이고, 끝나면 다시 넓힘. 화면 위에 "정전! 8" 남은 초. 방해꾼·유령 화면에는 작은 "정전 중" 표시만.
- **위장**: 다른 사람 눈에는 그냥 다른 캐릭터. 방해꾼 본인 화면에는 내 캐릭터 둘레에 점선 + "위장 중 7초".
- 얼음땡의 "술래가 가까우면 붉게 두근거림" 은 이 모드에서 **끈다** (정체가 드러나므로).

### 5-3. 회의 화면 (게임 화면 위에 덮는 창, 새 파일 `client/meeting.js`)
1. **시작 알림** (2초): 빨간 경광등 + "신고! 빨간 고양이의 얼음을 찾았어요" 또는 "긴급회의!".
2. **토론** (25초): 위에 "토론 시간 — 교실에서 말로 이야기해요" + 남은 초 막대. 가운데 카드 격자(최대 10장, 2줄×5). 투표 버튼은 아직 눌리지 않음.
3. **투표** (15초): 카드를 누르면 "빨간 고양이에게 투표할까요? [투표] [취소]" (실수 방지 한 번 더 확인). 아래 큰 "건너뛰기" 버튼. 투표하면 내 화면에 "투표 완료", 다른 사람 카드에 체크 표시. 내 카드·유령 카드는 누를 수 없음. 유령·도중 입장자는 "이번 회의는 지켜보기만 해요".
4. **결과** (3.5초): 카드마다 받은 표 수(작은 점). 제외된 사람이 있으면 그 캐릭터가 화면 밖으로 날아가는 연출 + 정체 문구(설정에 따라). 없으면 "아무도 제외되지 않았어요 (동점/건너뛰기)".
- 회의 화면이 떠 있는 동안 이동 조이스틱·버튼은 숨긴다.

### 5-4. 역할 안내·결과 화면

### 5-5. 선생님 화면 변화

- 위쪽: 남은 긴급회의 횟수.
- **학습 기록 창·CSV**: "역할" 열(학생/방해꾼), 유령일 때 푼 문제 표시.

## 8. 자동 시험 항목 (서버, 웹소켓 가짜 학생으로)
1. 방해꾼 찾기 모드로 시작이 된다 (`mode_not_ready` 가 안 나온다).
2. 4명 → 방해꾼 1명, 8명 → 2명. 선생님이 3명을 골라도 6명이면 2명으로 줄어든다.
3. 선생님 지정: 지정한 학생이 방해꾼이 된다. 학생 화면 어떤 메시지에도 지정 목록이 없다.
4. 정체 숨기기: 학생이 받는 `room` 에 다른 사람의 `role`·`solved` 가 없다. 방해꾼은 동료의 역할을 받는다. 선생님은 모두 받는다.
5. 얼음땡 `room` 메시지는 지금과 같다 (기존 시험 82개 모두 통과).
6. 얼리기: 시작 15초 전에는 안 됨, 거리 100 밖은 안 됨, 쿨타임 25초, 방해꾼·유령은 못 얼림, 학생은 `tag` 를 보내도 아무 일 없음.
7. 얼려지면 `ghost: true`, 얼음 흔적 생김, 열린 문제 창 닫힘, 다른 살아 있는 학생은 `freeze` 이벤트를 받지 않고 그 사람의 `ghost` 도 모른다.
8. 살아 있는 학생이 받는 `state` 에 유령 위치가 없다. 유령은 모두의 위치를 받는다.
9. 유령 학생이 문제를 맞히면 복구율이 오른다.
10. 방해꾼이 문제를 맞히면 본인 `solved` 는 오르고 복구율은 그대로. 기록에 `role: 'chaser'`.
11. 정전: 쿨타임 40초(팀 공용), 시작 15초 전 불가, `sabo.blackoutMs` 가 모두에게 간다, 이벤트에 쓴 사람 id 가 없다.
12. 문 잠금: 가장 가까운 잠글 수 있는 문이 잠긴다, 잠긴 문을 지나가려는 `pos` 는 되돌린다, 문 칸 안에 있던 사람은 빠져나올 수 있다, 7초 뒤 풀린다, 300 안에 문이 없으면 쿨타임을 안 쓴다.
13. 위장: 다른 학생이 받는 그 방해꾼의 `color`·`character` 가 바뀐다, 10초 뒤 돌아온다, 3번째는 거부.
14. 신고: 흔적 110 안에서만, 유령은 불가, 방해꾼은 가능. 회의가 열리고 흔적이 사라진다.
15. 긴급회의: 학생만, 1인 1회, 총 횟수(기본 3) 넘으면 거부, 시작 15초 안은 거부, 버튼 90 밖은 거부.
16. 회의 중: 시계가 멈춘다(회의 뒤 남은 시간이 회의 전과 같다), `pos`·`open`·`tag`·`sabotage` 무시, 열린 문제는 기록 없이 닫힌다.
17. 투표: 유령·도중 입장자는 거부, 자기 투표 거부, 두 번째 투표 거부, 모두 투표하면 바로 결과.
18. 제외 규칙: 단독 최다 + 건너뛰기보다 많음 → 제외 / 동점 → 없음 / 최다가 건너뛰기와 같음 → 없음. 누가 누구를 찍었는지는 어떤 메시지에도 없다.
19. `reveal` 꺼짐이면 결과에 `role` 이 없다.
20. 승패 ①: 마지막 방해꾼 제외 → 학생 승리 `all_found`.
21. 승패 ②: 복구율 100% → `restored`.
22. 승패 ③: 얼리기로 학생 수 ≤ 방해꾼 수 → `outnumbered` (회의 없이 바로).
23. 승패 ④: 시간 끝 → `time_up`. 회의 중에는 시간이 끝나지 않는다.
24. 회의가 끝나면 모두 시작 자리 둘레, 얼리기 쿨타임 15초.
25. 도중 입장: 학생·살아 있음. 회의 중 입장하면 그 회의 투표 불가.
26. 방해꾼이 끊겨 60초 뒤 정리되면 승패 확인 (마지막 방해꾼이면 학생 승리).
27. 게임이 끝나면 모두가 모든 역할을 받는다.
28. 선생님 `meetingCtl`: 연장 2번까지, "바로 투표" 동작, 학생이 보내면 무시.
